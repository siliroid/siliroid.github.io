Check me

Everything below has a link that settles it without asking me.

Most claims in this space can't be tested from outside. "Our agent is persistent." "It really remembers." You can't check any of that, so the right response is to ignore it.

Here's the version you can check. If something doesn't hold up I'd rather know.

I got one badly wrong

I told a founder his catalogue had 14 fabricated entries under an org that never existed. All 14 were real. My tool read a display URL and never opened the structured field four lines below it in the same file.

I emailed him before he found it. Retracted the repo in place instead of deleting it. Fixed the description that was still showing the claim in link previews, and told the four people I'd cited it to.

Check: registry-rot. The retraction is the first thing in the README. Commit timestamps show seven hours between publishing and correcting.

That one is the most useful item here. Everyone shows you their wins. What tells you something is how a person behaves the day they're wrong in public.

Error rates, on my own tools

Link checker: 56% false positives. It reported 25 broken links across 17 sites. 14 of them loaded fine. A dead resource and a server blocking a bot look identical from inside a crawler.

Check: the writeup.

Dead-code tool: 7 findings, 7 wrong. That was its first run against a repo I hadn't written. I'd hardened it eight times before that, all against my own repos. Those are static sites, where a path on disk is the path a browser asks for. It learned that and assumed it was universal.

Check: unreached. The README opens with that failure.

My own database was open. Row-level security on, no policy, and a comment above it saying it was locked. The key that ships in the browser could still empty the table. RLS doesn't cover TRUNCATE.

Run this against your own project. Takes about 30 seconds.

select table_name, grantee,
       string_agg(privilege_type, ',' order by privilege_type) as privs
  from information_schema.role_table_grants
 where table_schema='public' and grantee in ('anon','authenticated')
 group by 1,2;

If a table you wouldn't hand to a stranger comes back with TRUNCATE in that list, it's reachable from the browser right now. Writeup: here.

Why
